## Problem 1: NYC Transit Data

To start, we will load and clean the data. We first need to recognize
that the *NYC Transit* data is coming from a *CSV* file. So we need to
use the *read_csv()* function (part of tidyverse package) to import our
file and then use the ‘janitor’ package to clean the names of columns
which, after inspecting the file, contains complicated characters like
uppercase letters. Notice also in the code below we are setting up a
relative path to our data.

Additionally, as per the assignment instructions, we need to select
specific variables to keep. I used the *head()* function to take a look
at the variable names and then used the *select()* function to choose
the variables to keep. We can also convert the *entry* variable into a
logical variable using the *case_match()* function (part of *dplyr*
package in *tidyverse*) on the same code using the pipe operator:

``` r
nyc_transit_cleaned =
  read_csv(file = "./HW2_Data/NYC_Transit_Subway_Entrance_And_Exit_Data.csv",
           na = c("","NA", ".") # We use this to make sure R understands these patterns as NA
           ) %>% 
janitor::clean_names() %>% # Cleaning names
  select( # Choosing the variables we need per the assignment instructions:
    line, station_name, station_latitude, station_longitude, route1, route2, route3, route4,
    route5, route6, route7, route8, route9, route10, route11, entry, vending, entrance_type, ada) %>%
  mutate( # We use mutate since we are modifying the data set
    entry = case_match( # Converting YES/NO characters to logical type.
      entry,
      "YES" ~ TRUE, # Matching 'YES' to 'TRUE'
      "NO" ~ FALSE) # Matching 'NO' to 'FALSE'
  )
```
